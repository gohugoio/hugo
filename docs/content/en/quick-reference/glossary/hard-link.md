title: hard link

A _hard link_ is a file system feature that allows multiple file names to point directly to the exact same data on your disk. Unlike shortcuts or symbolic links that only reference another file path, a hard link acts as an equal owner of the underlying content. Editing the file through one name updates it everywhere, and moving or deleting one path leaves the file intact until all associated links are deleted.
